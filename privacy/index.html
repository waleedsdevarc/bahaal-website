Privacy Policy

This is a plain-language summary of what this website does and does not do with visitor information. Bahaal itself is a volunteer repair project, not a data company, and this site is kept as simple as the project it documents.

What this site does not do

This site has no login, no contact form, no newsletter signup, and no analytics or advertising scripts that we added. We do not collect names, emails, or any other personal information from visitors through this site.

What is collected automatically

This site is hosted on GitHub Pages. Like most web hosts, GitHub's servers automatically log standard technical data for every visit, such as IP address and browser type, under GitHub's own privacy statement. We do not control or access these logs ourselves.

The site also loads two fonts (Poppins and Work Sans) from Google Fonts. Loading a font from Google's servers means Google may log standard request data such as IP address, under Google's privacy policy.

About the household data shown on this site

The Approach and Impact pages show example entries from our internal service and cost logs. Household and family names are never published; entries are labeled with anonymised numbers such as "Household 3, DC Road" instead. This data describes work the project has done, not information collected from website visitors.

Questions

If you have a question about this policy or about the site, please open an issue on the project's GitHub repository.
